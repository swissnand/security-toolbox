# Sicherheitslücke melden

Danke, dass du hilfst, die Infosphera Security Toolbox sicherer zu machen.

- **Bitte keine öffentlichen Issues** für Sicherheitslücken.
- Melde sie vertraulich über [GitHub Security Advisories](https://github.com/swissnand/security-toolbox/security/advisories/new).
- Beschreibe kurz, was betroffen ist, wie es sich nachvollziehen lässt und welche Version du nutzt.

Wir bestätigen den Eingang innert 5 Arbeitstagen und halten dich über die Behebung auf dem Laufenden. Wer verantwortungsvoll meldet, wird auf Wunsch in den Release Notes genannt.

## Umfang

- Die Mac-App (Electron) und die Web-Version auf GitHub Pages
- Nicht im Umfang: Dienste Dritter, die die App abfragt (Cloudflare DNS, Have I Been Pwned, NVD)
